Immutable-release boundary

The tag earth-instrument-framework-v0.3.0 and its GitHub Release remain immutable. These corrections do not replace, edit, or reissue any PDF, archive member, checksum, tag, release asset, scientific claim, or verification result.

1. Where the AI-assistance disclosure appears

The original release-level wording said that all four preserved PDFs disclose language-model assistance and human responsibility on document-status pages. That is incorrect.

The 171-page main framework PDF contains the disclosure on its Document status page. The public ground reading, audit form, and verification report do not. The package-level acknowledgment applies to the project as a whole, but it should not be described as text printed in each companion PDF.

2. What v0.2.1 means

Statements that v0.3.0 supersedes v0.2.1 refer to an internal predecessor preserved inside the v0.3.0 source archive. No public v0.2.1 tag or GitHub Release was created. Version 0.3.0 is current only within the separately versioned Earth Is the Instrument supplemental line.
