How versions are organized

Core stable: SPPT/ASTRA v1.0.7 is the current core reference release and GitHub Latest; immutable v1.0.6 remains the historical baseline. Supplemental working paper: Earth Is the Instrument v0.3.0 is a separately versioned, immutable working-paper release. These are not peer reviewed and do not supply empirical planetary validation.

Research preview: Sector-Complete Instrument v0.1.0-alpha.1 is an alpha methods module. Superseded integration package: SPPT/ASTRA v1.0.7 Candidate Revision 2 remains an immutable prerelease snapshot; the stable core is now v1.0.7. GitHub uses the prerelease badge for these non-core lines because they are not the core/latest track.

Unpromoted drafts remain repository-visible outside these publication tracks. They do not become current editions, inherit the v1.0.7 citation, or receive a Pages route unless that boundary is stated explicitly.

About this format

The published HTML editions are the primary reading path: they reflow at narrow widths and retain document landmarks, headings, links, tables, image alternatives, and MathML. PDF and source artifacts remain separately downloadable for fixed-layout reading and exact reproduction; unpromoted drafts are read from their repository paths.

Original reference-release manuscript, documentation, figures, and generated data: CC BY 4.0. Software: MIT. Separately supplied resources retain the rights stated on their individual reading pages.
