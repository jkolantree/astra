# Publication history

ASTRA has one core reference line and several supplemental lines. This page is the human-readable map of what can be read, cited, reproduced, or inspected. Release specifications, checksums, and evidence records remain the authority for exact bytes.

## Status vocabulary

- **Current** — the present SPPT/ASTRA core reference and the target of the repository-level citation metadata.
- **Working paper** — a complete supplemental publication with its own version, citation, release, and evidence boundary. A GitHub prerelease badge keeps it outside the core/latest channel; it does not mean the work has been peer reviewed.
- **Draft** — public research material that remains open to scientific or editorial change. A draft may have a package or prerelease without becoming Current.
- **Archive** — a preserved historical edition, candidate, or superseded package. Archive links remain available so changes and negative results do not disappear.

These words describe publication state. Scientific statements use a separate vocabulary: **reported**, **derived under stated assumptions**, **inferred**, **proposed**, **unknown**, and **rejected**.

## Working paper

### Dark-Medium Response Atlas v0.1.0

*Path, Compensation, Memory, and Observation* is a supplemental response-methods paper. It separates gravitational role, collective charge response, material rest frames, and fundamental preferred-frame claims; develops conditional plasma-response derivations; and proposes held-out discriminators. It does not report a dark-matter detection or identify plasma, aether, and dark matter as one substance.

- [Read the versioned edition](https://jkolantree.github.io/astra/resources/dark-medium-response-atlas/v0.1.0/)
- [Open the tagged release](https://github.com/jkolantree/astra/releases/tag/dark-medium-response-atlas-v0.1.0)
- [Use the package citation metadata](resources/dark-medium-response-atlas/v0.1.0/CITATION.cff)

Its namespace-local `/resources/dark-medium-response-atlas/latest/` route is a convenience pointer, not an immutable citation target.

**Publication metadata note.** The immutable v0.1.0 files record `2026-09-01` as the artifact and edition date. GitHub records creation of the annotated tag and publication of the release on `2026-09-02`. The GitHub release display label, *Dark-Medium Response Atlas v0.1.0*, is abbreviated; the canonical citation title is *Dark-Medium Response Atlas v0.1.0 — Path, Compensation, Memory, and Observation*. This note clarifies the mutable public record; the immutable v0.1.0 files and release assets remain unchanged.

## DOI and repository boundary

These publication lines currently use versioned GitHub releases and Pages routes. No DOI or Zenodo record is claimed. Adding one is a separate publication action. The core and each supplemental line keep independent citation, release, checksum, rights, and reproduction records.
