# SPPT / ASTRA v1.0.7

## Stable current reference edition

SPPT / ASTRA v1.0.7 is the current stable core reference edition and GitHub
Latest release. It integrates the reviewed successor methods into one
versioned source tree while preserving the immutable v1.0.6 release as the
historical core baseline.

The scientific classification remains a not-peer-reviewed perspective and
mathematical framework with reduced synthetic demonstrations; no empirical
planetary validation is claimed. External studies are domain-specific
calibration records. They do not establish a common physical mechanism,
dark-matter detection, commercial catalyst performance, or a universal
arrow-of-time result.

## Release boundaries

The v1.0.7 release has its own source tree, claim matrix, source inventory,
generated HTML/PDF editions, checksums, and release identity. v1.0.6 is not
retagged, rewritten, or silently replaced. The public
`sppt-astra-v1.0.7-rc.2` package remains an immutable superseded review
snapshot; it is not mutated or relabeled.

*Earth Is the Instrument* v0.3.0 remains a supplemental working-paper release.
Sector-Complete Instrument v0.1.0-alpha.1 remains a research preview. Active
Support, Bridge Protocol, Cosmic Visibility, and Coherence-Cell resources
remain unpromoted drafts or prototypes. These tracks have separate identities
and do not inherit the v1.0.7 claim matrix or verification status.
