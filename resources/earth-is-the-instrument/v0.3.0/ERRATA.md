# Post-publication documentation errata for ASTRA Framework v0.3.0

- Recorded: 6 August 2026
- Applies to: `earth-instrument-framework-v0.3.0`
- Scope: documentation and version-line clarification only

The GitHub tag and release are immutable. This record does not replace, edit,
or reissue any PDF, archive member, checksum, tag, or release asset.

## AI-assistance disclosure

The release-level README, GitHub release notes, Pages guide, and offline package
README originally said that all four preserved PDFs disclose language-model
assistance and human responsibility on their document-status pages. That is
incorrect.

The **171-page main framework PDF** contains that disclosure on its Document
status page. The public ground reading, audit form, and verification report do
not contain the shared AI-assistance disclosure. The package-level
acknowledgment applies to the project as a whole, but it should not be described
as text printed in each companion PDF.

The corrected public wording is:

> The main framework PDF discloses language-model assistance and authorial
> responsibility on its Document status page. The three compact companion PDFs
> do not carry that disclosure; the release-level acknowledgment supplies the
> shared provenance and responsibility statement for the package as a whole.

## v0.2.1 predecessor

Statements that v0.3.0 supersedes v0.2.1 refer to an **internal predecessor
preserved inside the v0.3.0 source archive**. No public v0.2.1 tag or GitHub
Release was created. Version 0.3.0 is the current public edition only within the
separately versioned *Earth Is the Instrument* supplemental line.
