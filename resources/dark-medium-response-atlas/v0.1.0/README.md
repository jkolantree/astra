# Dark-Medium Response Atlas v0.1.0

*Path, Compensation, Memory, and Observation*

Status: supplemental working paper and methods proposal; not peer reviewed.

The Atlas asks a deliberately prior question: before an unexplained cosmic
response is given an ontology, what features of its motion, memory, phase, and
observation would let competing models part company?

The paper keeps plasma, condensate, preferred-frame, modified-gravity, and
gravitational dark-sector roles distinct. It develops an assumption-audited
linear-response benchmark, then uses three calibration cases to show why a
restored endpoint need not mean a restored state, why fitted parameters may
compensate, and why an observed response can lag an independently timed
perturbation.

## Evidence boundary

The paper distinguishes reported, derived under stated assumptions, inferred,
proposed, unknown, and rejected statements. It does not report a dark-matter
detection, identify plasma with aether, promote the Atlas into the stable
SPPT/ASTRA core, claim peer review, or establish scientific priority.

Substantive OpenAI Codex assistance is disclosed. Scientific judgment,
authorship, rights decisions, and publication responsibility remain with the
human project owner.

## Reproduction

The namespaced builder reads only the package release specification, authored
source, package CSS, declared ledgers, the repository runtime contract, and
the tested Atlas-local PDF-tagging and inspection helpers. It does not read
Git HEAD and never writes the frozen v1.0.7 documents.

Canonical build commands are documented in `RELEASE_NOTES.md`. Generated
identities and inspection records bind the final bytes. If the HTML or PDF
changes, those records and every affected publication gate must be replayed.
