# Supplemental ASTRA resources

This collection holds exploratory working papers and other public resources that
may inform later framework revisions. These files are versioned independently
from the immutable SPPT/ASTRA reference releases.

- [Earth Is the Instrument - Working Paper 0.1](earth-is-the-instrument/v0.1/)

An item in this collection does not amend the current framework release, enter
its claim-admission matrix, or inherit its verification status unless a later
SPPT/ASTRA release explicitly admits it.
