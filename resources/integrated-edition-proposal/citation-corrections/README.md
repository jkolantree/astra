# Atlas citation correction proposal

The preserved published v0.1.0 CFF declares top-level `type: article`, which the installed CFF 1.2 schema rejects: only `software` and `dataset` are accepted there. This successor describes the repository source package as software and places the paper in `preferred-citation` with `type: article`. It preserves the supplied author display name and article title and invents no DOI, author-name split, ORCID or journal.

The original versioned route is a bibliographic locator, not a digest or immutable-content guarantee. No new release version/date/license is assigned to this correction proposal. The source package retains mixed member-level rights. The historical `resources/dark-medium-response-atlas/v0.1.0/CITATION.cff` remains unchanged. A future published correction needs an explicitly selected successor route and publication review; the schema-valid draft is not that action.
